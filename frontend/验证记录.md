# 启学聊天前端验证记录

日期：2026-10-29。对应前端 v1.0，接口依据 keyan 后端源码（基于 77dd160）。

## 已验证

JavaScript 语法检查通过。自动测试 15 项通过，测试代码随前端保存在 `tests/` 中，可按 README 复现：

1. SSE 在中文 UTF-8 字节拆分与 CRLF 分隔下正确解析。
2. 并发请求遇到登录过期时只刷新一次令牌；重试使用新令牌；长会话 ID 保持字符串。
3. 刷新令牌时短暂网络失败不直接清除登录状态。
4. 确认失效的刷新令牌会清除会话；后端退出失败会向用户提示。
5. 本地代理转发授权信息和续传标记，保持流式响应；拒绝外来来源和私有文件路径；公开配置不包含后端密钥。
6. 延迟返回的旧 401 直接使用已刷新的令牌，不再多次刷新。
7. 切换账号后，旧请求不能返回旧账号数据或清除新登录。
8. 续传 410 时保留当前已有的部分回答。
9. SSE 业务错误终止本轮，不提供重复续读同一错误的按钮。
10. 退出后才返回的历史请求不能把私有消息重新显示。
11. Markdown 不执行原始 HTML，也不生成危险协议链接。
12. 聊天、赞踩及取消、改名、删除的页面状态和请求内容。
13. 断线重连只 GET 同一消息并携带 Last-Event-ID，不重复 POST 生成。
14. 历史消息与会话分页保留已有项、正确传递游标。
15. 匿名提问只打开登录窗口，不调用模型；登录规范化邮箱并加载历史。

新增用例先复现了续传丢失已有回答、终止错误重复续读、退出后历史重新渲染三处故障；修复后通过。另外处理了并发刷新与切换登录时的旧请求竞争。

页面逻辑测试通过 jsdom 执行真实 `app.js` 并提供受控接口响应，不等同于浏览器布局或真实后端联调。本次在 Windows 的 Node 20 和 Node 24 下均为 15 项通过；Linux 和 GitHub Actions 未验证。当前账号凭据无法写入 GitHub workflow 文件，因此 PR 保留可本地复现的测试，不包含自动检查配置。

上一版浏览器使用隔离的接口模拟服务验证：登录、流式消息、代码块、停止后继续读取同一回答、会话改名、赞踩，以及桌面和 390×844 手机布局。回答中的原始 HTML 被当作文字显示。页面无横向溢出。本次新增的自动交互回归不替代浏览器视觉复测；测试夹具仅供测试，不会调用真实模型。

前端 JavaScript 语法检查通过。交付内容核对不包含后端 .env 或其中的真实密钥。
